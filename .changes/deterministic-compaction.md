- Compaction now builds its summary from the session log without a model call (`compaction.engine: "deterministic"`, the default). The summary keeps your recent directions word for word, earlier requests, failures and what fixed them, edited files, and a short event transcript, within a size limit that shrinks for small context windows. Each compaction saves its state on the compaction entry and the next one continues from it, so nothing is summarized twice. Set `compaction.engine` to `"llm"` for the model-written summary. Like the other compaction settings, the engine is read when a session starts.
