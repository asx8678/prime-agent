- `/settings` has a sixth tab, **Advanced**, for the Rust-only runtime features: `Cache warming` (off / streaming / idle; global setting, applies from the next request), `Compaction engine` (deterministic / llm), `Auto-refine` and `Repeat guard` (on / off). The last three apply to new and reopened sessions. The tab is a Rust-only surface the TS menu does not have (pending sign-off in `next-steps/09-rust-divergence-signoff.md`).
- Writing `compaction`, `autoRefine` or `repeatGuard` from a settings row no longer fills `settings.json` with `null` for every field the user never set.
