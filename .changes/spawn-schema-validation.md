- `rlm.spawn` accepts `schema=` — a JSON Schema dict the child's collected result must satisfy. `rlm.collect` validates the child's settled answer against it in the parent kernel (TypeBox schemas are JSON Schema objects at runtime and carry over unchanged), reporting the first 5 validation errors on the collected result (`schema_valid`/`schema_errors`): no hidden retry, no child killed for an invalid result, and no new host surface — the schema never crosses to the host, so older hosts stay compatible.
